📁 Ciência de Dados 1 — Análise e Pré-processamento
Notebooks desenvolvidos na disciplina de Mineração de Dados, focados nas etapas fundamentais do pipeline de ciência de dados:
🔹 Medidas de Resumo e Gráficos — Análise estatística descritiva (média, mediana, desvio padrão) e visualização de dados com matplotlib e seaborn sobre datasets de salário e função.
🔹 Análise de Salários por País e Raça — Exploração do dataset Salary Dataset Based on Country and Race (Kaggle), com geração de histogramas usando a fórmula de Sturges e cálculo de estatísticas com Pandas.
🔹 Limpeza e Pré-processamento de Dados — Remoção de colunas desnecessárias, tratamento de valores nulos, normalização e preparação de dados para modelagem.
🔹 Árvore de Decisão — Avaliação de Carros — Classificação do dataset Car Evaluation com DecisionTreeClassifier do scikit-learn, com codificação de variáveis categóricas via LabelEncoder.
🔹 Regras de Associação — Implementação do algoritmo Apriori com mlxtend para descoberta de padrões em transações, baseado no livro Data Mining: Concepts and Techniques.
🔹 Avaliação 1 — Dataset de Vendas — Análise completa com limpeza, pré-processamento e classificação com Árvore de Decisão sobre dados de vendas imobiliárias.

📁 Ciência de Dados 2 — Machine Learning Avançado
Notebooks com foco em algoritmos de aprendizado de máquina supervisionado e não supervisionado:
🔹 K-means Básico e com Iris — Agrupamento com K-means aplicado a dados simples 2D e ao clássico dataset Iris, com visualização de clusters.
🔹 Agrupamento Hierárquico — Implementação de clustering hierárquico com dendrograma usando single-linkage, para definição de número ideal de clusters.
🔹 SVM — Support Vector Machine — Classificação do dataset Iris com SVM e comparação com outros classificadores, avaliando métricas de desempenho.
🔹 Naive Bayes — Avaliação de Carros — Classificação com GaussianNB e CategoricalNB no dataset Car Evaluation, com matriz de confusão e relatório de classificação.
🔹 kNN — Avaliação de Carros — Classificação com K-Nearest Neighbors, comparando resultados com os demais algoritmos aplicados ao mesmo dataset.
🔹 Regras de Associação — E-commerce — Mineração de padrões de compra em dataset real do Kaggle usando Apriori, com foco em InvoiceNo e StockCode.
🔹 Spotify — Análise e Classificação — Projeto de destaque: análise exploratória do dataset do Spotify seguida de classificação com Árvore de Decisão, integrando visualização, limpeza de dados e modelagem preditiva.
